## How I work

- **Start with the question.** Research and user journeys should shape what gets built.
- **Make the reasoning inspectable.** Write down assumptions, contracts and decisions so someone else can follow them.
- **Build in verifiable steps.** Keep implementation, testing, acceptance and release evidence distinct.
- **Design for real consequences.** Consider uncertainty, privacy, accessibility and the behavior a product encourages.
- **Keep learning after delivery.** Use research, operational evidence and feedback to guide the next improvement.

In practice, that means working across product strategy, UX, technical architecture, Python development, testing, documentation and delivery planning. I use AI-assisted development as part of that process, with human judgment and verification central to the work.
